# @boiboif/react-native-toast

A customizable native toast library for React Native New Architecture

## Installation


```sh
npm install @boiboif/react-native-toast
```


## Usage


```js
import { multiply } from '@boiboif/react-native-toast';

// ...

const result = multiply(3, 7);
```
